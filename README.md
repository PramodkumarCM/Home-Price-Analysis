# Home-Price-Analysis
This project focuses on predicting house prices using a simple linear regression model. The dataset contains information about house areas and their corresponding prices. After cleaning and preparing the data, a regression model was trained using scikit-learn to understand the relationship between area and price. The model demonstrated a positive linear trend, with predictions showing consistent price increases as area increases. Visualizations such as scatter plots were used to support the findings and validate the model’s effectiveness. This project provides a straightforward approach to building and interpreting linear regression for real-world predictions
